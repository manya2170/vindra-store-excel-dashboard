# Vrinda Store Excel Dashboard

## 📊 Project Overview

The **Vrinda Store Excel Dashboard** is an interactive sales and order analysis dashboard created in Microsoft Excel. It provides a clear overview of the store's sales performance, customer demographics, order status, sales channels, and top-performing states.

The dashboard uses interactive slicers to allow users to filter the analysis by **Month, Channel, and Category**.

## 🎯 Objectives

- Analyze monthly sales and order trends
- Compare sales between men and women
- Understand order delivery and cancellation status
- Identify the top-performing states
- Analyze customer age groups by gender
- Compare sales/orders across different channels
- Provide an interactive dashboard for business decision-making

## 📌 Dashboard Features

### 1. Orders vs Sales
- Monthly comparison of **sales amount** and **number of orders**
- Helps identify monthly sales and order trends

### 2. Sales: Men vs Women
- Shows the distribution of sales between male and female customers
- Helps understand customer demographics

### 3. Order Status
- Visualizes order fulfillment status
- Includes:
  - Delivered
  - Returned
  - Cancelled
  - Refunded

### 4. Sales: Top 5 States
- Identifies the five states generating the highest sales
- Helps understand geographical sales performance

### 5. Orders: Age vs Gender
- Compares orders across different age groups
- Segments customers by:
  - Adult
  - Senior
  - Teenager
- Further divided by gender

### 6. Orders: Channel
- Shows order distribution across different sales channels:
  - Amazon
  - Myntra
  - Flipkart
  - Ajio
  - Meesho
  - Nalli
  - Others

## 🎛️ Interactive Filters

The dashboard includes slicers for:

- **Month**
- **Channel**
- **Category**

These filters allow users to dynamically explore different segments of the store's sales and order data.
